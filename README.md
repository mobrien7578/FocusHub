# FocusHub
IoT project using Raspberry Pi, Sense HAT, and camera to monitor study environment and calculate focus score.

FocusHub: Smart Study Room Assistant

Student Name: Michael O’Brien
Student Number: 20119095

Project Description: 
The aim of this project is to design and build a smart connected study room assistant using Raspberry Pi, Sense HAT, and a camera to help focus on study. The system will monitor environmental conditions such as temperature and humidity and detect movement that causes distractions in the room using a camera. From the collected data the system will calculate a focus score to show how suitable the environment is for studying. 

The project will use networking technologies to send data collected from sensors between components and display results on a user-friendly dashboard. The dashboard will show live readings, session information, distraction counts, and trends. The system may also provide recommendations such as adjusting the conditions of the environment or reducing distractions to improve focus.
